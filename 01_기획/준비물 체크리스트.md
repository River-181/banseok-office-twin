# 준비물 체크리스트

## A. 막히는 것 (M2 전에 필요)
- [ ] 질문 5개 답변 → [[질문-답변]]
- [ ] **건물 도면 원본** — 건물관리사무소·총무 담당에 3층 평면도(PDF/CAD) 요청. 이거 하나면 방향·기둥·창·코어가 한 번에 해결돼서 가장 가성비 좋음
- [ ] 현장 사진 (아래 촬영 목록)

## B. 현장 사진 촬영 목록
입구에서 한 바퀴 돌면서, 각 사진에 방향이 드러나게.
- [ ] 엘리베이터 홀 → 사무실 출입문 (정면)
- [ ] 출입문 안쪽에서 사무실 전체 (네 모서리에서 대각선으로 4장)
- [ ] 창이 있는 벽 각각 (창대·멀리언 보이게)
- [ ] 천장 (조명·텍스 패턴), 바닥 (카펫/타일)
- [ ] 기둥 2개 근접
- [ ] 방으로 표시된 곳의 벽 (유리인지 확인용)
- [ ] 창밖 풍경 (서·남 방향) — 지형 모델 검증용

## E. 개발 환경 (내가 대신 못 하는 것)
- [ ] VWorld 오픈API 키 발급 (계정 생성은 직접) → `export VWORLD_API_KEY=...` 를 `~/.zshrc`에
- [ ] Claude Code 설치 확인 (`claude --version`)
- [ ] Python 3.11+ 확인 (`python3 --version`)
- [ ] `05_코드/setup.sh` 실행 → venv를 iCloud 밖(`~/.venvs/banseok3d`)에 생성
- [ ] (선택) Blender — 홍보용 렌더가 필요해질 때만
